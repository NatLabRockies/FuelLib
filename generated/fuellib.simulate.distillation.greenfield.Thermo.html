fuellib.simulate.distillation.greenfield.Thermo

class fuellib.simulate.distillation.greenfield.Thermo(fuel, P, *, ideal_solution, ideal_vapor)

Bases: object

Pure-component properties and vapor-liquid equilibrium on NumPy arrays.

Tabulate pure-component properties and set up the VLE models.

Parameters:

  • fuel (Fuel) – Fuel object.

  • P (float) – Pressure in Pa.

  • ideal_solution (bool) – Whether to use unit activity coefficients.

  • ideal_vapor (bool) – Whether to use unit fugacity coefficients.
