plot(ax=None, *, label=None, temperature_units='K', data=None, color=None, linestyle='-', marker=None, data_label=None, default_ymin=True)

Plot the D86 curve (D86 temperature vs. volume percent recovered).

Only the distillation period (recovered volume > 0) is plotted. Pass the returned axes to further calls to overlay several curves; each new curve takes the next color of fl_blue_4 and the temperature limits cover all curves. See fuellib.utils.plotting.plot_d86().

Parameters:

  • ax (Axes | None) – Axes to plot on. Defaults to the axes of a new figure.

  • label (str | None) – Legend entry of the curve. The legend is shown if any curve on the axes has a label. Defaults to None.

  • temperature_units (str) – Units of the temperature axis (e.g. "degC"). Defaults to "K".

  • data (tuple[Quantity[ndarray[tuple[int]]], Quantity[ndarray[tuple[int]]]] | None) – Measured recovered volume fractions and D86 temperatures, plotted as symbols in the color of the curve. Defaults to None.

  • color (str | None) – Color of the curve and the data symbols. Defaults to the next color of fl_blue_4.

  • linestyle (str) – Line style of the curve (e.g. "--"). Defaults to "-".

  • marker (str | None) – Marker style of the measured data. Defaults to the next style of the cycle.

  • data_label (str | None) – Legend entry of the measured data. Defaults to "Data: {label}".

  • default_ymin (bool) – Whether the lower temperature limit defaults to the standard temperature. If False, it is the tick below the data. Defaults to True.

Returns:

Axes containing the plot.
